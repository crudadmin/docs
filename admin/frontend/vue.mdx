The administration is a Vue 3 application. Components referenced from fields, buttons and layouts are loaded from the [component directories](/admin/configuration#vue-component-directory). This page covers the API available to them.

## Registering components
{/* feature: frontend.window.crudadmin, frontend.global-component-slots */}

Components added to `window.crudadmin.components` before the page loads become global components. Load the script with the [`scripts`](/admin/configuration#branding) configuration.

```js resources/js/admin.js
const components = import.meta.glob('./components/**/*.vue', { eager: true });

for (const path in components) {
    const name = path.split('/').pop().replace('.vue', '');

    window.crudadmin.components[name] = components[path].default;
}
```

A global component named `AppLogo` replaces the sidebar logo, `RightNavbarSlot` is rendered in the top navbar with the `user` prop.

## Models
{/* feature: frontend.getFreshModel, frontend.getActiveModel, frontend.model-tree */}

Every admin model is available in the model tree loaded with the administration.

```js
// new model instance from the model tree
const orders = reactive(getFreshModel('orders').initialize());

// model already rendered on the page
const school = getActiveModel('schools');
```

## Model events
{/* feature: frontend.model-events */}

`on()` accepts one event or a list and returns a function which removes the listener.

```js
const off = model.on(['create', 'update', 'delete'], () => reloadCalendar());

onUnmounted(off);

model.fields.date_from.on('change', (value) => {
    // ...
});
```

| Event | Payload |
| --- | --- |
| `create`, `onCreate` | created row |
| `update`, `onUpdate` | updated row |
| `submit`, `onSubmit` | row after create or update |
| `delete`, `onDelete` | removed ids, only from the default delete button |
| `fetched` | model after the first rows request |
| `buttonActionFire` | `{ rows }` returned by a button |
| `form.open` / `form.close` | opened row or `null` |
| `destroy` | model removed from the page |
| field `change` / `change.row` | new value / value loaded from the row |

## Modals and toasts

`Modal` and `Toast` come from `@crudadmin/helpers/modal` and are available as `window.Modal` and `window.Toast`.

```js
Modal.success('Saved.');
Modal.danger({ title: 'Error', message: 'Something went wrong.' });

if (await Modal.confirm({ title: 'Delete row?', message: 'This cannot be undone.' })) {
    // confirmed
}

const modal = Modal.open(MyComponent, { row }, { title: 'Detail', class: '--wide' });
const { action, value } = await modal.result; // 'success', 'cancel', 'close' or a custom action

Toast.success('Saved.');
Toast.error({ title: 'Error', message: 'Try again later.' });
```

Returning `false` from `success`, `cancel` or an action callback keeps the modal opened. A component opened in a modal receives it in the `modal` prop and closes it with `modal.close()`.

## Forms in a modal

The form of a model can be drawn in a modal instead of the page.

```js
model.modals.add(); // a new row
model.modals.edit(row.id); // an existing row
model.modals.view(row.id); // read only
model.modals.list(); // the whole table of the model
model.modals.form(); // the row the model has opened
model.modals.close();
```

A model which should open its own form in a modal announces it once with
`model.modals.enable()`. Models with the `form.modal` setting do it themselves.
