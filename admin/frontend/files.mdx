CrudAdmin stores files uploaded in the administration and gives you a file object to render them, resize images and serve downloads. File fields and their parameters are described in [File uploads](/admin/model/fields/uploads).

## Reading a file from a model
{/* feature: helper.admin-file */}

```php
$article = Article::find(1);

$image = $article->image; // Admin\Core\Helpers\Storage\AdminFile
```

Rendered as a string, the file returns its public URL, for example `https://example.com/uploads/articles/image/my-photo.jpg`.

```blade
<article>
    <h2>{{ $article->name }}</h2>
    <img src="{{ $article->image }}" alt="">
</article>
```

| Property | Value |
| --- | --- |
| `$file->url` | public URL |
| `$file->filename` | `my-photo.jpg` |
| `$file->extension` | `jpg` |
| `$file->exists` | `true` when the file is in the storage |
| `$file->basepath` | absolute path on the disk |

A `multiple` file field returns a collection of file objects.

## Resizing images

`resize($width, $height)` takes the width as its first argument and the height as its second. With both defined, the image is cropped to the exact size. With only one defined, the other is calculated from the ratio.

```blade
<img src="{{ $article->image->resize(200, 100) }}" alt="">
<img src="{{ $article->image->resize(400) }}" alt="">
<img src="{{ $article->image->resize(null, 300) }}" alt="">
```

`resize()` returns a new file object pointing to the resized image. SVG files are returned unchanged.

<Note>
  The image is resized on the first request and stored in a cache for later requests.
</Note>

## Advanced image operations

The file object uses [Intervention Image](https://image.intervention.io/), so it can perform any operation that library supports.

The `image($mutators)` method takes an array whose keys are the function names and whose values are the arguments of those functions.

```blade
<img src="{{ $article->image->image([
    'fit' => [200, 200],
    'blur' => 10,
]) }}" alt="">
```

This example crops the image with `fit` and then blurs it with `blur`.

## Helper methods

### delete

Removes the file from the storage and returns `true`, or `false` when the file does not exist. The column value is not changed.

```php
$row->image->delete();
```

### download

Returns a signed URL which downloads the file. It works for [private files](/admin/model/fields/uploads#private-files) too.

```blade
<a href="{{ $row->contract->download() }}">Download the contract</a>
```

### filesize

Returns the size in bytes. Pass `true` for a formatted size.

```blade
{{ $row->contract->filesize() }}      {{-- 2048 --}}
{{ $row->contract->filesize(true) }}  {{-- 2 KB --}}
```
