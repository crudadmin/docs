An admin model is a regular Laravel [Eloquent model](https://laravel.com/docs/eloquent) from the MVC architecture. The difference is that an admin model carries parameters and settings from which CrudAdmin generates the database, the forms and the validation.

<Tip>
  For the bigger picture of how the generation works, read [How it works](/admin/how-it-works).
</Tip>

## What you get

1. The whole database and the administration interface are generated from the admin model settings.
2. Relations between models are mapped automatically. You no longer write relation methods — calling a method named after the related model binds the relation, for example `$article->gallery()` or `$article->gallery`.
3. `$fillable` and `$casts` are filled automatically from the defined fields.
4. And more.

## Creating an admin model
{/* feature: command.admin:model */}

Admin models are created with **php artisan**.

```bash
php artisan admin:model Article
```

The command creates `app/Models/Article.php`, or `app/Article.php` when the `Models` directory does not exist.

```php app/Models/Article.php
<?php

namespace App\Models;

use Admin\Eloquent\AdminModel;
use Admin\Fields\Group;

class Article extends AdminModel
{
    protected $migration_date = '2026-01-10 10:00:00';

    protected $name = 'Article';

    protected $title = '';

    protected $belongsToModel = null;

    public function fields()
    {
        return [
            'name' => 'name:Name|placeholder:...|required|max:90',
            'content' => 'name:Content|type:editor|required',
            'image' => 'name:Image|type:file|image|required',
        ];
    }
}
```

| Option | Generated parameter |
| --- | --- |
| `--name=Articles` | `$name` |
| `--title="Blog articles"` | `$title` |
| `--group=blog`, `-g` | `$group` |
| `--single`, `-s` | `$single = true` |
| `--localization`, `-l` | `$localization = true` |
| `--sortable` | `$sortable = false` |
| `--publishable`, `-p` | `$publishable = false` |
| `--minimum=1`, `--maximum=5` | `$minimum`, `$maximum` |

A name starting with the plural of an existing admin model sets the parent: `admin:model ArticlesComment` generates `protected $belongsToModel = Article::class;`. A name ending with `Gallery` generates a multirows image field.

Then create the table with `php artisan admin:migrate`, see [Migrations](/admin/model/migrations).
