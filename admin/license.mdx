</Warning>

## License key

Set your license key in the CrudAdmin configuration.

```php config/admin.php
/*
 * License key
 */
'license_key' => 'your-license-key',
```

To obtain a license key, contact [sales@gogoldev.com](mailto:sales@gogoldev.com).
