**CrudAdmin** is currently released as a free system that requires a free license key, which is present in the system right after installation. The future of the system will be built on paid license keys that unlock its full functionality.

Current users are not affected — projects launched before licensing was introduced stay untouched by any future changes to the sales terms.

```php config/admin.php
/*
 * License key
 */
'license_key' => 'campaign2019',
```
