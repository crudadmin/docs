## Creating admin request
{/* feature: helper.admin-model-request */}
{/* feature: command.admin:request */}

```bash
php artisan admin:request CustomerRequest
```

The command creates `app/Http/Requests/CustomerRequest.php`. Each method is optional.

```php app/Http/Requests/CustomerRequest.php
<?php

namespace App\Http\Requests;

use Admin\Core\Requests\AdminModelRequest;

class CustomerRequest extends AdminModelRequest
{
    public function authorize()
    {
        return auth()->check();
    }

    // Validate only these model fields
    public function only()
    {
        return ['firstname', 'lastname', 'email'];
    }

    // Add new fields or append rules to model fields
    public function merge()
    {
        return [
            'terms' => 'required|accepted',
        ];
    }

    // Replace rules of model fields
    public function replace()
    {
        return [
            'email' => 'required|email',
        ];
    }
}
```

Use it with `Customer::validator()->use(CustomerRequest::class)` or `->only(CustomerRequest::class)`.

When `authorize()` returns `false`, the request is aborted with `401`.

### `rules`

`rules()` is a shortcut for `only()` + `merge()`: only listed fields are validated, and their rules are appended to the model rules.

```php
public function rules()
{
    return [
        'phone' => 'required',
        'coupon' => 'nullable|size:8',
    ];
}
```
