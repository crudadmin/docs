The core of CrudAdmin is three packages: `crudadmin/crudadmin`, `crudadmin/framework` and `crudadmin/resources`. Everything else is an optional package. Install it only when your project needs the feature.

Every package is installed with composer from the repository `packages.crudadmin.com`. Set it up once per project as described in [Installing the licensed packages](/admin/license#installing-the-licensed-packages).

## Supported versions

| Package | Version | CrudAdmin |
| --- | --- | --- |
| `crudadmin/helpers` | 2.x | 6 |
| | 1.3 | 4, 5 |
| `crudadmin/socialite` | 2.x | 6 |
| | 1.x | 3 to 5 |
| `crudadmin/api` | 1.x | 6 |
| `crudadmin/website` | 1.x | 6 (in CrudAdmin 5 and older, these features are part of `crudadmin/crudadmin`) |
| `crudadmin/gutenberg` | 4.x | 6 |
| | 3.x | 5 |
| | 2.x | 4, 5 |
| `crudadmin/skeleton` | 1.x | 6 |

The PHP and Laravel requirements come from the CrudAdmin version. CrudAdmin 6 requires PHP 8.3 and Laravel 12 or 13.

## Which package do I need?

| You are building | Packages |
| --- | --- |
| Only an administration | none |
| A Blade website managed from the administration | `crudadmin/website`, optionally `crudadmin/gutenberg` |
| A Nuxt or Ionic app with its own API | `crudadmin/helpers`, optionally `crudadmin/socialite` |
| An integration or AI agent reading and writing admin models | `crudadmin/api` together with `crudadmin/helpers` |

## Other packages

These packages exist as well, but they are not documented here yet:

| Package | Purpose |
| --- | --- |
| `crudadmin/autoajax` | JSON responses with messages, validation errors and store data, used by `autoAjax()`. Required by CrudAdmin. |
| `@crudadmin/helpers` (npm) | Shared frontend layer for Vue, Nuxt and Ionic: API client, gettext translator, Pinia stores, modals and toasts. This is a different package from the PHP `crudadmin/helpers`. |
| `crudadmin/eshop` | E-shop module with products, orders and a cart |
| `crudadmin/invoices` | Invoices, PDF export and QR payment codes |
| `crudadmin/payments` | Payment gateways connected to invoices |
