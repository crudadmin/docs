CrudAdmin is built on top of the **Laravel** framework and gives your project one consistent structure to program against.

It is designed for developers and companies building web and mobile database applications. It removes the repetitive steps of a project — **database design, user interface, form validation** and working with data — so you describe your data once and get the rest.

## What it covers

A Laravel model with an extra layer of parameters is called an **Admin model**. Once the admin model exists, everything below is generated from it.

## History

CrudAdmin was first released in early **2016**. It grew out of a large, complex project, where it was written to speed up development.

The potential of the system was clear early on, so the core was split off into a separate project and gradually adopted across more projects.

## Who uses CrudAdmin

After several years of development, CrudAdmin runs **hundreds of web applications, e-shops, information systems and mobile applications** that connect to its API for their data.

It is used by a number of **Slovak** and **Czech** companies, and it is intended to grow into the global market.

## Testing

CrudAdmin ships with automated **unit** and **integration** tests covering most of the functionality in the system.

Before every release, its components are checked on several test environments. Integration tests boot the application automatically and verify its behaviour in a browser.
