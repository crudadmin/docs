---
title: "Introduction"
description: "CrudAdmin is a Laravel administration built on top of Eloquent models. Define a model once and get migrations, an admin interface, validation and an API for free."
---

CrudAdmin extends Eloquent models with a field definition. From that single definition it generates database migrations, the administration interface, validation rules and the frontend forms, so the model stays the only place you describe your data.
